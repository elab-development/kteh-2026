# Klijentske veb tehnologije i skriptni jezici (2025/2026)

Ovaj repozitorijum je namenjen za čuvanje i organizaciju kodova sa predmeta **Klijentske veb tehnologije i skriptni jezici** za školsku 2025/2026 godinu.

Repozitorijum sadrži materijale sa vežbi, uključujući početne (kostur) projekte i finalne verzije koda razvijene tokom časa.

---

## 📂 Organizacija repozitorijuma

Kodovi su organizovani po granama (_branches_), gde svaka grana odgovara jednoj vežbi.

Nazivi grana sadrže:

- redni broj vežbe
- tip materijala:
  - `kostur` – početni kod (kostur za rad na času)
  - `final` – konačno rešenje sa vežbi

### Primeri:

- `vezbe-01-kostur`
- `vezbe-01-final`
- `vezbe-02-kostur`
- `vezbe-02-final`

Na ovaj način je omogućeno:

- lakše praćenje toka vežbi
- jasno razlikovanje početnog i finalnog koda
- samostalno vežbanje na osnovu skeleton verzija

## 🚀 Kako koristiti repozitorijum

### 1. Kloniranje repozitorijuma

```bash
git clone https://github.com/elab-development/kteh-2026.git
```

---

### 2. Pregled dostupnih grana

```bash
git branch -a
```

---

### 3. Prelazak na željenu vežbu

```bash
git checkout naziv-grane
```

Primer:

```bash
git checkout vezbe-03-kostur
```

---

### 4. Ažuriranje repozitorijuma

```bash
git pull
```

---

## 📌 Kako koristiti materijale sa vežbi

Preporučeni način rada:

1. Otvoriti `kostur` verziju vežbe
2. Samostalno implementirati rešenje
3. Uporediti sa `final` verzijom
4. Analizirati razlike i unaprediti kod
